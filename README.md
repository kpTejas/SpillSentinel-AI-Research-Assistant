# SpillSentinel AI — Source-Grounded Research Assistant

## Project Overview
SpillSentinel AI is a Generative AI research assistant developed using Google NotebookLM as part of the BSERC GenAI Internship Week 1 Project.

The project helps students and researchers explore satellite-based maritime oil-spill detection, drift analysis, and AIS-based vessel attribution using trusted research sources.

## Features
- Source-grounded question answering with citations
- Research document summarization
- Audio and Video Overviews
- Mind maps, reports, quizzes, and flashcards
- Infographics and slide decks
- Multilingual learning support

## Methodology
The project integrates nine trusted research sources into Google NotebookLM. The assistant was configured and evaluated through source selection, citation verification, research question testing, and educational content generation.
